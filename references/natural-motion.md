# 自然人腿与穿鞋动作（natural）

用户给人腿/鞋子动作图并要求自然、修长、不要僵硬时选本模式。角色身份与服装取自用户原图，动作参考只决定轮廓、相机和姿态；不要把参考图的脸、蝴蝶结、袜口或水印搬进角色。

本模式的姿态规则覆盖经典模式的“柱状直腿、完整鞋底朝镜头、最大压力明显压扁”描述。默认命令仍兼容 classic；选择 natural 必须显式传参。

## 单帧构图

- 固定轻微侧面三分之四视角、鞋尖朝左。小腿有自然弧度，由腿肚逐渐收细到脚踝；实体填色不等于粗直圆柱。
- 在 160×256 单格里，以鞋长约 125–150px、小腿中段宽约 38–55px、脚踝宽约 25–38px 为初始构图目标，按参考微调。不要画成超长小腿配一双小鞋，也不要刻意夸张肢体。
- 腿从上边界继续到画外；鞋底最下像素贴底边。鞋长、鞋跟、鞋面带和袜子款式跨帧固定。
- 服装遵从原图：连裤袜不改成长袜，鞋子不脱掉。所有帧使用相同画布尺寸和留白，纯透明背景，不画地面与阴影。
- 鞋子通过脚踝转动表现动作。鞋长和鞋跟高度保持稳定；鞋底仅在自然可见的角度露出，不强迫整只鞋底正对镜头，不把皮鞋压成扁饼。

## 必须绘制的 12 张素材

前脚 front_0..5 共六张、后脚 back_0、四张头像 normal_0/normal_1/excite_0/excite_1、endscreen。

| 帧 | 姿态（每格单独生图，不拼整张表） | 生成参考 |
|---|---|---|
| front_0 | 小腿自然倾斜，脚踝舒展，鞋尖略向下，轻盈抬脚 | 用户服装图与动作参考 |
| front_1 | 同一条腿向下，脚踝开始回勾，鞋尖接近水平 | front_0 |
| front_2 | 鞋尖略抬、鞋跟准备先触地，角度在前后帧之间 | front_1 |
| front_3 | 刚触地，鞋底接近水平，脚踝自然收住 | front_2 |
| front_4 | 脚掌落实，重心前移，小腿轻微前倾 | front_3 |
| front_5 | 压实后的稳定姿态，脚踝继续小幅前移，保持鞋型 | front_4 |
| back_0 | 同一双鞋的远景落地姿态，腿完整延伸到顶边 | front_3 |

六张前脚图必须逐帧生成，不能复用 front_0 充当 front_1/2，也不能用镜像、程序旋转整条腿或插值代替脚踝动作。用户关心动作连贯时，同组按顺序生成并上传前一帧参考。后脚其余压力帧与头像后期档位仍可沿用首版复用，交付时说明。

## 合成与检查

~~~sh
python scripts/build_sheet.py --frames frames/ --base generic.png --motion natural --name "MY OC"
python scripts/validate.py --sheet /path/to/output.png --base generic.png --report /path/to/output.report.json
~~~

natural 默认 --paw-fit width：先裁透明边，再等比按宽缩放、底对齐，过长的小腿从顶部裁掉。不会拉伸腿脚；如果原始素材的小腿太短或鞋子占满整个图，必须重画，合成无法补齐解剖。可用 --paw-fit contain 保留全部素材。

校验从 report 自动读取 motion；没有 report 时用 --motion natural。自然模式不要求“高压轮廓面积增加”或每步轮廓变化达 10%，仍检查透明度、腿部填充、贴地、跨帧突变、重复前脚图以及 UI 像素。它无法判断脚踝是否自然，必须目检六格动作。

## 目检

按 front_0 → front_1 → front_2 → front_3 → front_4 → front_5 查看：小腿轮廓平滑收细、相机固定、脚踝逐步弯曲、鞋长不忽大忽小、触地鞋底朝下、服装一致。不要把“每张不一样”误当作动作连贯。
